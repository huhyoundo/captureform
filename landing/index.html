Features

필요한 모든 캡처 기능

단순한 스크린샷을 넘어, 생산성을 극대화하는 스마트 캡처 경험

◱

영역 캡처

마우스 드래그로 원하는 영역만 정확하게 캡처합니다. 이미지와 파일 경로가 동시에 복사됩니다.

Ctrl + Shift + C
🔍

OCR 텍스트 추출

캡처한 이미지에서 텍스트를 자동으로 추출합니다. 한국어, 영어, 일본어 모두 지원합니다.

캡처 후 OCR 버튼
🎬

GIF / MP4 녹화

선택 영역을 GIF 또는 MP4로 녹화합니다. 버그 리포트나 튜토리얼 제작에 완벽합니다.

캡처 후 REC 버튼
📋

클립보드 히스토리

복사한 텍스트와 이미지를 최대 50개까지 기록합니다. 언제든 다시 꺼내 쓸 수 있습니다.

Ctrl + Alt + V
📌

핀 윈도우

캡처한 이미지를 항상 최상위에 고정합니다. 참고 자료를 보면서 작업할 때 유용합니다.

캡처 후 Pin 버튼
📁

파일 위치 열기

클립보드의 file:/// URL을 감지하여 해당 파일이 있는 폴더를 탐색기에서 바로 엽니다.

Ctrl + Shift + X
Clipboard History
